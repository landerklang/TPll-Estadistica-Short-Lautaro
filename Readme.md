# Como Hacer funcionar el archivos

para hacer que los archivo funcione debe de primero
crear una entorno virtual para hacer esto debes de escribir en la termina:
_uv venv env_
si no tiene activado el uv entonce escriba lo siguiente:
_python -m venv nombre_entorno_
luego se debe de activar los entorno utilizando lo siguiente:
_.\env\Scripts\activate_
y por ultimo debe de instalar las dependencias:
_pip install pandas matplotlib numpy_

no se olvide que la primera ves que ejecute todos las cajas de texto deben de instalar las jupyter entorned
